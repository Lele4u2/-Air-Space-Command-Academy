# Air & Space Command Academy ✈️

An interactive educational aircraft and space-capabilities academy for OTS study.

## Play the game

Once GitHub Pages is enabled using **Settings → Pages → Deploy from a branch → main / (root)**, the expected site address is:

https://lele4u2.github.io/-Air-Space-Command-Academy/

> Publishing has to be enabled in repository settings if it is not already active.

## Included modes

- **Aircraft Hangar:** interactive aircraft reference cards, pictures via Wikipedia/Wikimedia where accessible, strengths and weaknesses, simple explanations and text-to-speech.
- **Command:** fictional Operation Harbor Relief turn-based airlift game.
- **Force Request:** cargo/patient/aircraft assignment with scenario debrief.
- **Strike Package:** four-step educational force packaging: desired effect → weapon and aircraft → threats → detached support, followed by an illustrative fictional scenario.
- **Weapons:** aircraft-weapon matching for classroom learning; historically derived source descriptions require verification.
- **Library, Quiz, Logistics, Scenario Builder, Settings** and saved progress.

## Run locally

Download `index.html` and open it in a modern browser. Some external photographs require an internet connection; a fallback illustration is provided when no photo loads.

## Important scope

These are educational fictional exercises, not a live operational planner. AFEX and OPS each have separate authorized rules and available assets. Do not publish restricted training materials or instructor-only scenario data to a public repository.

This is a **single-player browser prototype**, not yet a finished multiplayer 3D simulator. Aircraft photos depend on Wikipedia page image availability, and browsers may block external APIs or images.

## Maintenance

The full application currently lives in `index.html` for simple GitHub Pages hosting. Before extending it further, add automated browser tests and split data, UI and game rules into modules.
